# G-Major-Reborn
🎸 G-Major Reborn | Reconstrução independente do TC Electronic G•Major e GLydian em C++17/JUCE. Processador de efeitos para guitarra com DSP, VST3, 8 racks individuais, MIDI/SysEx e aplicativo Standalone. Desenvolvido para oferecer maior flexibilidade e controle na produção musical.
