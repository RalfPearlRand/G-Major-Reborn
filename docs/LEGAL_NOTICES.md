# Avisos legais e de compatibilidade

G-Major Reborn é um projeto independente, sem afiliação, autorização, patrocínio ou endosso da TC Electronic, GLydian ou de seus titulares.

“TC Electronic”, “G•Major” e “GLydian” são usados apenas para identificar o equipamento e o software com os quais o projeto busca interoperar. As marcas e os direitos sobre os produtos de referência pertencem a seus respectivos titulares.

Este repositório não distribui o executável GLydian, o manual do fabricante nem bancos de presets de fábrica. Os presets incluídos foram criados para este projeto. A interface, os algoritmos de áudio e os detalhes de compatibilidade são implementações independentes; diferenças e limites conhecidos estão documentados em [KNOWN_DIFFERENCES.md](../KNOWN_DIFFERENCES.md).

Este aviso descreve a intenção e os materiais presentes no repositório; não concede autorização de terceiros nem determina, por si só, a legalidade de qualquer atividade de engenharia reversa.
